출하품번 → 소재품번 매칭

수주는 완제품 품번, 주조는 소재 품번이라 이름이 다릅니다. 아래 순서로 먼저 맞는 것을 씁니다.

  1. 소재매핑표에 확정_소재품번이 있으면 그 값 사용
  2. 공백·기호·괄호를 지우고 같은지 비교 5632480-01 → 563248001
  3. 끝 구간을 떼고 비교 (도면 개정·사양 차이)
  4. LH/RH, PORT/STBD 좌우가 같은지 확인
  5. 남은 품번은 가장 비슷한 후보를 제시만 함

소재 하나를 여러 출하품번이 같이 쓰면 한 그룹으로 묶어 출하량을 합칩니다.
