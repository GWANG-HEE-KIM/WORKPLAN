# 주조 생산계획 수립 프로그램 사용법

## 실행
1. `설정.json`을 메모장으로 열어 **계획연도·계획월·파일 이름**을 바꾼다.
2. `생산계획_실행.bat`을 더블클릭한다. (약 20초)
3. 끝나면 `결과\YYYY-MM\` 폴더에 파일이 생기고 계획 엑셀이 자동으로 열린다.

## 폴더 구성
| 파일 | 내용 |
|---|---|
| 생산계획_실행.bat | 실행 파일 (더블클릭) |
| production_plan.ps1 | 프로그램 본체 (PowerShell) |
| 설정.json | 월, 입력 파일, 계획 기준 |
| 소재매핑표.csv | 완제품 품번 → 소재 품번 확정표 (계속 누적해서 사용) |
| 결과\YYYY-MM\ | 계획 엑셀, 품번매칭_결과.csv |

입력 엑셀(수주, 금형·가공 재고, 전월 계획)은 `자료폴더`(기본: 상위 폴더 `D:\Ai_교육_다운로드`)에 둔다. 엑셀에서 열려 있어도 읽을 수 있다.

## 설정.json 항목
| 항목 | 설명 | 11월 값 |
|---|---|---|
| 계획연도 / 계획월 | 계획할 달 | 2026 / 11 |
| 수주파일 | 월별 출하계획 파일. 머리글의 날짜(예: 2026-11-01) 열을 자동으로 찾음 | 월별수주현황_11월.xlsx |
| 금형재고파일 / 가공재고파일 | 고객사·품번·품명·품목구분·SUM 열이 있는 재고 파일 | 재고현황_금형/가공_재고여부.xlsx |
| 전월계획파일 / 전월계획시트 | 제품별 일일 생산수량을 가져올 전월 계획 시트 | 2026년 11월 생산계획_v0.xlsx / 10월 계획 (단가인상분) |
| ...시트 | 비워 두면 첫 번째 시트 | "" |
| 안전율 | 필요량에 곱하는 여유율 | 1.05 |
| 익월선행비율 | 다음 달 출하 중 미리 생산할 비율 | 0.5 |
| 가공재고인정_품목구분 / _품번표시 | 가공 재고 중 재고로 인정할 행 | 완제품 / 출하대기 |
| 휴무일 | 주말 외 쉬는 날 (일자 숫자) | [] |
| 격주생산 | 같은 라인에서 주 단위로 번갈아 생산하는 품목. `첫주`는 그 달 첫 근무주에 생산할 쪽(A 또는 B) | A=스웨벨, B=트란솜 822865·822866, 첫주 B |
| 완료후열기 | 끝나면 엑셀 자동 열기 | true |

## 계획 기준 (프로그램이 하는 일)
1. **품번 매칭**: 품번 끝의 공정 표시 `(소재)`, `(OP10)` 등을 떼고 맞춘다. 소재와 완제품 품번이 다르면 같은 고객사 안에서 품번·품명이 비슷한 것끼리 연결하고(LH/RH·PORT/STBD 반대는 제외), **소재매핑표.csv의 확정값을 최우선**으로 쓴다.
2. **재고** = 금형 재고 전부 + 가공 재고 중 '완제품'·'(출하대기)' 행
3. **필요량** = (당월 출하 + 익월 출하 × 선행비율) × 안전율 − 재고 (소재 단위로 합산)
4. **하루 생산량** = 전월 계획 시트의 제품별 일일 수량(가장 많이 쓴 값). 부족해도 늘리지 않고 '미달'로 표시. 전월 이력이 없는 품목만 월 균등배분.
5. **격주 생산** 품목은 지정한 주에만, 전월 요일별 수량으로 배치
6. 나머지는 연속 근무일로, 하루 총 부하가 가장 적은 구간에 배치

## 결과 엑셀
- **주조 생산계획**: 전월 계획과 같은 양식 (재고·출하·선행분·총생산·일별·주조합계·이월재고), 고객사별 소계. 일별 칸을 고치면 합계가 자동 계산된다.
- **산출근거(출하품번별)**: 출하품번마다 출하·재고(전체/인정)·필요량·매칭 방법
- **확인 필요**: 생산 미달, 소재 미확인, 전월 일생산 없음, 매핑 검토, 소재 후보 확정 필요

## 매달 반복 순서
1. 새 수주·재고 파일을 자료폴더에 넣고 `설정.json` 수정 (월, 파일 이름, 전월계획시트, 휴무일, 격주 `첫주`)
2. 실행 → '확인 필요' 시트 확인
3. 소재가 연결 안 된 신규 품번은 `소재매핑표.csv`에 자동으로 추가된다. `확정_소재품번` 칸을 채우고 (소재가 없으면 `없음`) 다시 실행
